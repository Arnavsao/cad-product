01

DXF round-trip

Open a file from your desk, edit it, write it back out. Layers, blocks, dimension styles and text all survive the trip, so {{ appName }} slots into a toolchain that already runs on DXF instead of asking everyone to move.

02

Layouts and viewports

Model space is where you draw; paper space is where you decide what gets printed. Place viewports at a real scale, fill in the titleblock, and plot the sheet to PDF or SVG — the same drawing can carry a detail sheet and a general arrangement without duplicating any geometry.

03

Associative dimensions

A dimension is attached to the geometry, not typed next to it. Stretch the wall and the measurement updates itself — which is the difference between a drawing you can trust and a drawing you have to re-check. Twelve object snaps, dimension styles, hatch and tables come with it.

04

Blocks and attributes

Draw a door once, then place it forty times. Every instance points back at one definition, so correcting the original corrects the drawing — and attributes let each instance carry its own tag, which is what turns a plan into a schedule.

Snap markers use the AutoCAD glyphs, so the square, triangle and circle mean what they have always meant.
